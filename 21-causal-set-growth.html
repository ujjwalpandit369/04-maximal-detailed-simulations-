Beginner's Guide: A Universe of Atoms and Causality

What if spacetime, like matter, is made of fundamental, indivisible "atoms"? This is the core idea of the Causal Set (or "causet") hypothesis. In this view, the universe is not a smooth, continuous sheet, but a collection of discrete points. But a random collection of points isn't spacetime; it needs structure. The Causal Set theory proposes that the most fundamental structure is the order of events: the network of cause and effect. Some events are in the past of others, some are in the future, and some are unrelated ("spacelike separated").

This simulation shows a universe being "born" and "growing" according to these principles. Each dot is a spacetime atom. A line from a lower dot to a higher dot means the lower one is in the direct causal past of the upper one. The simulation follows a simple "Classical Sequential Growth" model. At each step, a new spacetime atom is born. It then randomly forms causal links to some of the already existing atoms, declaring them to be in its past. The rule of transitivity (if A caused B, and B caused C, then A must have caused C) is then enforced to create a consistent causal history. You are watching the structure of spacetime itself emerge from a simple, stochastic process, one event at a time.

Core Theory: The Causal Set Hypothesis and Sequential Growth

The Causal Set Hypothesis is an approach to quantum gravity that posits that the fundamental structure of spacetime is a discrete, partially ordered set of spacetime events. The entire geometry of spacetime—distances, volumes, curvature—is proposed to be emergent from the causal relationships between these events. A causal set (causet) `C` is a set with a relation `≺` that is:

  • Transitive: If `x ≺ y` and `y ≺ z`, then `x ≺ z`.
  • Acyclic (Causal): If `x ≺ y`, then `y ⊀ x`.
  • Locally Finite: For any `x, z ∈ C`, the set of elements `y` such that `x ≺ y ≺ z` is finite.
The primary challenge is to find the dynamics that govern the formation of such a causet—the "quantum gravity" of the system. The most studied model for this is Classical Sequential Growth (CSG). This is a stochastic process that grows a causet `C_n` of `n` elements into `C_{n+1}` by adding a new element `e_{n+1}`. The new element randomly chooses a subset of `C_n` to be its direct ancestors. The full set of its ancestors is then the transitive closure of this chosen subset.
In this simulation, the growth proceeds as follows:
  1. A new element `e` is created.
  2. For each existing element `x ∈ C_n`, a link `x ≺ e` is formed with probability `p`.
  3. The causal past of `e`, denoted `Past(e)`, is constructed. An element `y` is in `Past(e)` if it was chosen in step 2, OR if there exists an element `x` chosen in step 2 such that `y ≺ x`. This enforcement of transitivity is crucial.
The parameter `p` in this model is a free parameter. Different choices of `p` can lead to causets with different macroscopic properties. While this is a "classical" growth model, it is a stepping stone towards a full quantum theory where the growth process itself would involve a superposition of different possible "next" events.

The visualization of a causet is non-trivial. Since there is no background manifold to embed the points in, the layout must be derived from the causal structure itself. This simulation uses a "layered" or "rank-based" embedding. The rank of an element is the number of elements in the longest chain of causal relations in its past. The vertical axis represents the rank, providing a natural notion of "time" or "duration" emerging from the causal structure.
