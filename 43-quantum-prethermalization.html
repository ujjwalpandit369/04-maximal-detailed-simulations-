Exposition: The Arrow of Time in a Quantum World

Beginner's Guide: Why Don't Humpty Dumpty's Pieces Reassemble?

One of the deepest questions in physics is why time seems to flow in only one direction. A cup of coffee cools down but never spontaneously heats up. This is the essence of the second law of thermodynamics: systems tend toward thermal equilibrium. But what does "equilibrium" mean for a perfectly isolated quantum system, like a chain of atomic spins, that isn't connected to a hot or cold bath? The modern answer is that the system acts as its own bath. Information about its initial state gets scrambled among its many interacting parts until, for all practical purposes, it's lost. The system has "thermalized."

However, some special quantum systems, called **integrable systems**, are too orderly to scramble information effectively. They have hidden conservation laws that prevent them from ever truly thermalizing. They remember their initial state forever. This simulation explores what happens when we take such a special, integrable system and give it a tiny "kick" (`ε > 0`) to break its special property. The result is **prethermalization**: the system rapidly relaxes not to a true thermal state, but to a long-lived, non-thermal "plateau." It gets stuck in a state that looks like the equilibrium of the original, special system. Only on a much, much longer timescale will it eventually succumb to the chaos of the perturbation and drift towards true thermal equilibrium.

Core Theory: ETH, Integrability, and Prethermal Plateaus

The modern understanding of quantum thermalization is rooted in the **Eigenstate Thermalization Hypothesis (ETH)**. ETH posits that in a generic, chaotic (non-integrable) quantum system, every individual energy eigenstate already "looks thermal." This means that if you prepare the system in any state that is a superposition of many energy eigenstates, it will dephase over time, and the expectation values of local observables will relax to the thermal average predicted by statistical mechanics.

This simulation explores a system that can be tuned between two regimes. The base model is the **1D Heisenberg XXZ spin chain**, whose Hamiltonian is:
H_XXZ = Σ [ SᵢˣSᵢ₊₁ˣ + SᵢʸSᵢ₊₁ʸ + Δ SᵢᶻSᵢ₊₁ᶻ ]
This model is famously **integrable**, meaning it has an extensive number of local conserved quantities beyond just energy. These additional conservation laws severely constrain the dynamics, preventing the system from exploring its entire phase space. Consequently, integrable systems violate ETH. When started in a non-equilibrium state, they relax to a **Generalized Gibbs Ensemble (GGE)**, a non-thermal steady state that remembers all the initial values of its conserved quantities.

We then add a small, **integrability-breaking perturbation**:
H = H_XXZ + ε Σ SᵢᶻSᵢ₊₂ᶻ
This next-nearest-neighbor interaction `ε` breaks the special symmetries of the XXZ model. For any `ε > 0`, the system is now non-integrable and is expected to thermalize according to ETH. However, for small `ε`, the "memory" of the nearby integrable system is powerful. The system first undergoes a rapid relaxation to a **prethermal state** that is nearly identical to the GGE of the `ε=0` model. This creates a long-lived plateau in the value of local observables. The timescale to relax away from this plateau and towards the true thermal state is very long, scaling as `τ ~ 1/ε²`. This simulation allows you to directly visualize this prethermal plateau.

Advanced Details: Implementation via Exact Diagonalization

Simulating the time evolution of a quantum many-body system is computationally hard because the size of the Hilbert space grows exponentially with the number of particles, `dim = 2^L` for a spin-1/2 chain of length `L`. This simulation handles a system of `L=10` spins, corresponding to a state vector with 1024 complex components. To evolve the state, we must solve the Schrödinger equation `d|ψ⟩/dt = -iH|ψ⟩`.

This is achieved by first constructing the `1024 x 1024` Hamiltonian matrix `H`. Because the interactions are local (acting only on nearest or next-nearest neighbors), the matrix is very **sparse** (mostly filled with zeros). We can exploit this sparsity to store the matrix and perform matrix-vector multiplication efficiently. The time evolution is then carried out using a high-fidelity numerical integrator, the **4th-order Runge-Kutta (RK4)** method, which repeatedly applies the Hamiltonian to the state vector to step it forward in time. The initial state is prepared as a "domain wall" `|↑↑↑↑↑↓↓↓↓↓⟩`, which has high energy and is easy to construct, making it a standard choice for studying relaxation dynamics.

Interactive Elements Guide

This simulation shows the relaxation of a local observable in a quantum spin chain.

  • Start/Pause/Reset: Control the time evolution. Resetting is required after changing any slider, as the entire Hamiltonian must be rebuilt. This may take a moment.
  • Perturbation (ε): This is the key control. It sets the strength of the integrability-breaking term.
    • Set `ε = 0.00`. The system is perfectly integrable. Run the simulation and watch the "Central Spin Magnetization" plot. The value will relax to a stable, non-zero value and stay there forever. This is the non-thermal GGE steady state.
    • Set `ε` to a small value, like **0.10**. Run the simulation. You will see the central spin relax to almost the *exact same plateau* as the `ε=0` case. This is the prethermal plateau. If you could run for long enough, you would see it slowly decay to zero (the true thermal state), but this decay is too slow to see in the simulation's runtime.
    • Set `ε` to a large value, like **0.50**. Now the perturbation is strong. You will see the observable relax much more quickly towards zero, bypassing the prethermal plateau entirely.
  • Anisotropy (Δ): This slider changes the nature of the underlying integrable model, which in turn changes the value of the prethermal plateau.
  • Spin Configuration Plot: This shows the magnetization `⟨Sᵢᶻ⟩` at each site. You can watch the initial sharp domain wall "melt" and spread across the system.
  • Central Spin Plot: This is the main plot for observing prethermalization. It tracks the magnetization of the spin at the center of the chain as a function of time.
