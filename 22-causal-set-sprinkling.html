Beginner's Guide: Finding the Dots in the Masterpiece

If the universe is fundamentally a discrete set of "spacetime atoms" (a causal set), how can it give rise to the smooth, continuous spacetime of Einstein's General Relativity that we know works so well? This simulation shows the connection. Here, we start with a continuous spacetime—in this case, the simple, flat spacetime of special relativity, called Minkowski space. Time flows from bottom to top.

The process of "sprinkling" is like throwing a handful of sand onto a canvas. We randomly drop a number of spacetime atoms into the continuous spacetime. Once the points are placed, we use the rules of the background spacetime to determine their causal relationships. An event A can only cause an event B if you can get from A to B without traveling faster than light. The lines of causality, the "light cones," are straight lines at 45-degree angles. Any event inside the future light cone of another is its causal future. After determining all these relationships, we have "found" the causal set that is embedded within this continuum.

Click on any event. You will see its causal past highlighted in blue and its causal future highlighted in red. You are seeing the fundamental causal structure that was hidden within the smooth spacetime. The core idea of the Causal Set program is that if you sprinkle points with a high enough density, the information in this discrete network of relationships is enough to reconstruct all the geometric properties—distances, time, curvature—of the original continuous spacetime.

Core Theory: Poisson Sprinkling and Lorentz Invariance

A key requirement for any theory of discrete spacetime is that it must be compatible with Lorentz invariance, the fundamental symmetry of special relativity. A simple fixed grid of points, for example, would violate this, as it has preferred directions. The Causal Set hypothesis solves this by using a random process called a Poisson sprinkling to generate the set.

The process is as follows:

  1. Start with a continuous Lorentzian manifold (spacetime) `(M, g)` with volume `V`.
  2. Choose a density `ρ`. The number of elements to be sprinkled is `N = ρV`.
  3. Randomly place (sprinkle) `N` points into the manifold `M`. This process is Lorentz invariant; because the points are placed randomly, there is no preferred frame or grid.
  4. For every pair of sprinkled points `x, y`, determine their causal relationship using the metric `g`. If `y` is in the future light cone of `x`, we say `x ≺ y`.
The result is a discrete partial ordering of `N` elements which is, by construction, a causal set. The fundamental conjecture of the program is that this underlying causet is the "real" physics, and the continuous manifold is just a good approximation at low energies. The correspondence is `Number of elements ≈ Volume / Planck_Volume`.

This simulation performs a sprinkling into 2D Minkowski space. The metric is `ds² = -dt² + dx²`. An event `e₁ = (t₁, x₁)` is in the causal past of `e₂ = (t₂, x₂)` if `t₁ < t₂` and the interval is timelike: `Δs² = -(t₂-t₁)² + (x₂-x₁)² < 0`. This is equivalent to `(t₂-t₁)² > (x₂-x₁)²`, or `|Δt| > |Δx|` (with `c=1`), which is the condition used in the code to determine the causal links `≺`.
