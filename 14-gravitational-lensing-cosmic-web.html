Beginner's Guide: Seeing the Invisible

How can we map out dark matter if it's invisible? We use a cosmic trick predicted by Einstein's theory of General Relativity: gravitational lensing. The theory tells us that massive objects curve spacetime around them. Light, which normally travels in a straight line, follows this curvature. This means a massive object, like a cluster of galaxies (or more accurately, the dark matter halo it lives in), can act as a giant magnifying glass, bending and distorting the light from galaxies located far behind it.

This simulation is a two-step process that shows you how astronomers use this effect. First, click "Run N-body Simulation." This will run a simulation just like the previous ones to create a realistic cosmic web of dark matter on the left canvas. This is our "lens." Once it's done, the "Activate Lensing" button will appear. The right canvas shows what we "see" through this lens. The background is a uniform grid of dots (or a galaxy, which you can select). The light from this background passes through our dark matter lens, and its path is bent. The result is a distorted image. Where the mass density is high, the distortion is strong, creating beautiful arcs and magnifying the background. By studying these distortions, astronomers can work backwards and create a map of the invisible dark matter that must be causing them. You are, in effect, doing the same thing as a research astronomer: using light as a tool to see the unseen.

Core Theory: The Lens Equation and Inverse Ray Shooting

Gravitational lensing is described by the lens equation, which maps positions in the source plane (the true position of the background object, `β`) to the image plane (where we see the object, `θ`).
β = θ - α(θ)
The key ingredient is the deflection angle `α(θ)`, which is determined by the gravitational potential `Φ` of the lensing mass distribution. Specifically, `α` is the gradient of the 2D projected potential: `α = ∇Φ`. In this simulation, the potential `Φ` is calculated from the N-body particle distribution using the Particle-Mesh method.

To create the lensed image, we use a technique called inverse ray shooting. Instead of tracing rays from the source to the observer (which is inefficient, as most rays don't reach the observer), we trace them backwards from the observer's screen (the image plane) to the source plane. The algorithm is as follows:

  1. First, run an N-body simulation to produce a realistic mass distribution and calculate its 2D gravitational potential `Φ(x,y)`.
  2. For each pixel `θ = (θ_x, θ_y)` on the lensing canvas (the image plane):
  3. Calculate the deflection angle `α(θ)` by taking the numerical gradient of the stored potential grid `Φ`.
  4. Use the lens equation `β = θ - α` to find the corresponding position `β = (β_x, β_y)` on the source plane.
  5. Look up the color of the source plane at position `β`. This may require interpolation if `β` falls between pixels on the source grid.
  6. Set the color of the pixel at `θ` to the color found in the previous step.
This process is repeated for every pixel on the screen to build up the final, distorted image. The resulting patterns of distortion, known as "shear" (stretching) and "convergence" (magnification), directly trace the underlying mass distribution, providing a powerful way to map dark matter.
